# Exercício 11 – Sequência de Fibonacci
Escreve um programa que lê um inteiro N e imprime os primeiros N termos da sequência de Fibonacci (0, 1, 1, 2, 3, 5, …), separados por espaço. Usa uma função int fibonacci(int n) que retorna o n-ésimo termo.
