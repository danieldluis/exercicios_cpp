# Exercícios de C++

Exercícios práticos de C++ para completar.

## Como funciona

1. Abre a pasta do exercício e lê o `enunciado.md`.
2. Completa o código no `main.cpp`.
3. Compila e testa:
`g++ main.cpp -o main` && `./main`
4. Verifica a solução em `solutions/`.
